# Key Design Decisions（关键决策记录）

> 每一条都是「选了什么、否了什么、为什么」。被否方案与选择理由同等重要——它们记录了
> 真实权衡，而非事后合理化。

## D1. 记忆写满：做生命周期，不做扩容

- **被否**：提高上限（治标——只进不出的系统迟早再满）；一次性人工瘦身（违背自动化原则）；接入外部记忆服务（双写冲突、数据外流、理念不符）
- **采纳**：记忆生命周期四道门（整合 / 巩固配额 / 蒸馏 / 复核）。记忆有进有出，配额是**有界性保证**而不是仓库容量

## D2. 规则驱动，而非统计校准

- **背景**：单用户数据量撑不起统计校准；「自动化=统计校准」会让自动化永远无法启动
- **采纳**：确定性规则 + 保守阈值 + 可逆兜底，零统计样本可运行。校准环只是数据充足后的优化，**不是运行前提**

## D3. 永不删除：superseded + quarantine + git

- **采纳**：物理删除在代码层禁用（L4 动作 demo 期直接不实现）。矛盾/过时条目标 `superseded` 移入隔离区，保留期后转归档；每日 git 快照全量可回滚
- **理由**：撤销能力决定修改自由度——「可撤销」比「阈值准」更可靠地兜住自动化的错误

## D4. LLM 不判「稳定 vs 瞬时」

- **被否**：让 LLM 在蒸馏时一次性判断某条记忆是「稳定特质」还是「瞬时事实」
- **理由**（双 agent 独立审查共识）：单次观察无时间维度，LLM 自由裁量不可靠，且画像级错误会**自我强化**（错误特质注入 → 塑造后续会话 → 再蒸馏又读它）
- **采纳**：稳定性由规则判定（跨会话计数 + 时间跨度），LLM 只做措辞生成

## D5. 写入整合是独立 gate，不是改核心脚本

- **背景**：提取管道是受保护的核心组件
- **采纳**：整合逻辑做成**保护区外的独立脚本**（读候选 → 写详情/隔离区/日志）。可独立测试、可拔掉即回退、不扩大核心变更面——同时满足低耦合与保护区纪律

## D6. 挤出排序：高价值保护，而非纯 LRU

- **事故**：纯 LRU 挤出曾把**高频行为规则**（如「代码偏好」「项目启动准则」）挤出常驻区——它们影响每轮行为，离开常驻 = 行为退化
- **采纳**：两段式挤出——第一段排除「高价值」（其同源详情条目已达标可提升）条目；第二段才强制合规。加 30 天冷却防「提升↔挤出」震荡

## D7. 免写判定：完整包含，而非前缀包含

- **事故**：前缀包含判定（L2 前 30 字符被 L1 条目包含）会把「L2 未覆盖的尾部信息」静默丢弃
- **采纳**：只有「L1 条目被某条 L2 **完整包含**」才允许挤出后不落盘；否则一律先落盘再挤

## D8. 召回/评测：伪 gold + 判定线，而非公开基准

- **背景**：单用户没有标准答案集，公开基准（PersonaMem 等）的前提（已知画像的标注集）不成立；生产与评判同模型，测的是自洽不是质量
- **采纳**：伪 gold（历史会话中「实际被使用过的记忆」）+ 五维判定线；**门禁非调参**——评测只判过/不过，不做提升曲线叙事（防 Goodhart）

## D9. 不用向量检索

- **被否**：混合检索（BM25+向量+RRF）是 2026 年记忆系统的行业共识
- **理由**：本地单用户规模 + 成本敏感 + 中文分词复杂度；规范化字符串 + LCS 已覆盖实际需求。**共识方向的取舍要有自己的成本账**，记入路线图而非盲目跟随

## D10. 观察期 30 天

- **采纳**：画像候选先隔离观察 30 天，到期复查源条目仍有效才提升
- **理由**：把画像错误的放大效应从「立即注入」降为「延迟注入」；观察期内源失效 → 候选作废

## D11. 同义才替换

- **事故**：相似度 0.45 阈值曾把「互补的、更具体的行为规则」用 LLM 弱版本整条替换
- **采纳**：包含关系或相似度 ≥0.8 才替换；相似但非同义 → 追加；替换前整块匹配（§ 分块，非子串）；旧文完整入隔离区

## D12. 工程纪律：原子写 / 并发锁 / 即时提交 / dry-run 无副作用

- 文件写回一律临时文件 + `os.replace`；修改前备份
- cron 与手动并发 → O_EXCL 锁文件，重入跳过
- 幂等指纹每个动作后**即时提交**（崩溃窗口不破坏幂等）
- `--dry-run` 只报告：不建目录、不建表、不落日志

## D13. 评测的「安全弃答」维度

- 采纳自 LongMemEval 的 abstention 维度：抽样常驻条目由 LLM 判「可疑/过时/可能误导」
- 意义：**注入质量与注入数量同等重要**——错误自信比缺失更危险。实测该维度真能发现过时条目
